Project 3: Correlation Heatmap & Pairwise Analysis
This project explores the 10000 Sales Records.csv dataset to analyze relationships between numeric variables. It calculates Pearson correlation coefficients, visualizes them using heatmaps, and identifies key positive and negative relationships.

✨ Features
Pearson Correlation: Computes the correlation matrix for all numeric columns.

Heatmap Visualization: Generates a masked, annotated correlation heatmap using Seaborn.

Pairwise Relationships: Creates pairplots/scatter matrices for the top numeric variables.

Relationship Summary: Extracts and prints the top 5 strongest positive and negative correlations.

📦 Prerequisites
Make sure you have the following Python libraries installed:

pip install pandas numpy seaborn matplotlib
